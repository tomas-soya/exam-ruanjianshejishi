# 第八章 算法设计与分析

## 1. 常用算法设计五大核心策略全方位对比

| 算法策略 | 核心思想 | 必备核心特征 | 求解目标与搜索方式 | 经典代表问题 | 能否保证全局最优 |
|---|---|---|---|---|---|
| **分治法 (Divide & Conquer)** | 将大问题分解为若干**相互独立、与原问题形式相同**的子问题，递归求解后合并 | 子问题相互独立、可分可合 | 递归自顶向下，合并自底向上 | 归并排序、快速排序、折半查找、最近点对问题、Strassen 矩阵乘法 | **视问题而定**（取决于分解与合并逻辑的最优性证明） |
| **动态规划法 (Dynamic Programming)** | 将问题分解为相互重叠的子问题，**用表格自底向上保存子问题解**，避免重复计算 | **最优子结构**、**重叠子问题** | 自底向上查表填表，空间换时间 | 0-1 背包、矩阵连乘、最长公共子序列 (LCS)、Floyd 最短路、装配线调度 | 是（穷举所有有效状态） |
| **贪心法 (Greedy Algorithm)** | 依据某种贪心准则，每一步都做出**当前看来最好的局部最优选择**，不回溯 | **最优子结构**、**贪心选择性质** | 迭代一步步做出局部选择，无回溯 | 分数/部分背包、Prim/Kruskal 最小生成树、Dijkstra 最短路、哈夫曼编码 | **视问题而定**（部分背包可得最优；0-1背包、TSP 仅得近似解） |
| **回溯法 (Backtracking)** | 选定约束条件，**深度优先搜索 (DFS)** 问题的解空间树，发现不符合要求时回退剪枝 | 解空间树、剪枝函数（约束/限界） | 深度优先搜索，遇不通则回溯 | 八皇后问题、0-1 背包回溯求解、图的着色、旅行商问题 | 是（系统搜索所有可能解） |
| **分支限界法 (Branch & Bound)** | 在解空间树中进行**广度优先 (BFS)** 或**以最小耗费/最大价值优先**搜索，剪枝寻找最优解 | 解空间树、上界/下界函数、活结点表 | 广度优先或优先级队列式搜索 | 单源最短路径（带界）、0-1 背包分支限界、批处理作业调度 | 是（求最优解） |

### 回溯法核心特征与易错辨析
- **核心机制**：回溯算法是一种试探性搜索算法，通常采用**深度优先搜索（DFS）**在问题的解空间树中进行遍历，并通过**剪枝操作（约束函数排除不合法解、限界函数剪去得不到最优解的子树）**提前终止无效搜索路径，从而大幅提高搜索效率；
- **经典避坑辨析**：
  1. **求解效率对比**：对存在重叠子问题的问题，**动态规划算法通常比回溯算法效率更高**（回溯在最坏情况下可能需要遍历全部可能路径，时间复杂度呈指数级）；
  2. **可解性判定**：**0-1 背包问题完全可以使用回溯算法求解**（将物品选择转化为二叉子集树，结合重量约束与价值上界剪枝），绝非“只能用动态规划”；
  3. **空间开销特性**：回溯法虽然无需保存全部历史子问题的表格解，但其**严重依赖递归调用栈**，当树深度达到 O(n) 时系统栈空间占用显著，不能笼统认为其“空间复杂度一定较低”。

## 2. 算法渐进复杂度分析与主定理（Master Theorem）

### 主定理（Master Theorem）通用求解法则
求解形如 T(n) = a T(n/b) + f(n) 的分治递归递推式（其中 a ≥ 1, b > 1）：
先计算分水岭临界阶：n^(log_b a)，再将 f(n) 与 n^(log_b a) 进行渐进比较：
1. **情况一（递归分支占主导）**：若存在 ε > 0 使得 f(n) = O(n^(log_b a - ε))（即 f(n) 多项式低于临界阶）：
   T(n) = Θ(n^(log_b a))
   *例*：T(n) = 4T(n/2) + n log n。由于 n^(log_2 4) = n^2，而 n log n 增长率远低于 n^2，故 T(n) = Θ(n^2)。
2. **情况二（两项同阶平衡）**：若存在 k ≥ 0 使得 f(n) = Θ(n^(log_b a) log^k n)：
   T(n) = Θ(n^(log_b a) log^(k+1) n)
   - *例 1*：T(n) = 2T(n/2) + Θ(n)（归并排序）。n^(log_2 2) = n^1，与 f(n) = n 同阶（k=0），故 T(n) = Θ(n log n)；
   - *例 2*：T(n) = 2T(n/2) + n log n。由于 a=2, b=2，n^(log_2 2) = n^1；合并项 f(n) = n log n = n^1 log^1 n（即 k=1），满足情况二，直接得出渐近紧致界为 T(n) = Θ(n log^(1+1) n) = Θ(n log^2 n)。
3. **情况三（非递归合并项占主导）**：若存在 ε > 0 使得 f(n) = Ω(n^(log_b a + ε)) 且满足正则条件 a f(n/b) ≤ c f(n)（c < 1）：
   T(n) = Θ(f(n))

### 常见时间复杂度大小排列
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)

### 初始排列对经典算法时空复杂度的影响
- **数据基本有序（正序）时**：
  - **直接插入排序**：只需比较 1 次无需移动，时间复杂度达到最优线性 O(n)，空间复杂度为 O(1)；
  - **快速排序**：若固定选择首尾元素作为枢轴，基本有序将成为快速排序的最坏输入（每次划分极其不平衡），时间复杂度退化为 O(n^2)；虽然辅助交换空间为原地 O(1)，但**空间复杂度（主要为递归调用栈空间）会从平均的 O(log n) 退化到最坏的 O(n)**。
- **数据完全反序时**：
  - 直接插入排序达到最坏 O(n^2)；
  - 堆排序、二路归并排序依然保持稳定的 O(n log n)。

## 3. 经典算法模型深度解析

### 背包问题：0-1 背包 vs 分数背包（部分背包）
- **0-1 背包问题**：每个物品要么完整装入、要么不装，不可切分。
  - **设计策略**：**动态规划法**（或回溯/分支限界）；
  - **时空复杂度**：时间复杂度为 Θ(nW)（n 为物品数，W 为背包容量），属于**伪多项式时间**；空间复杂度通过滚动数组可优化为 O(W)；
  - **贪心策略失效原因**：局部单位价值高并不代表组合总价值最高，贪心法无法求得 0-1 背包的最优解。
- **分数背包（部分背包）问题**：物品可以任意分割装入。
  - **设计策略**：**贪心算法**；
  - **算法步骤**：计算各物品的单位价值 v_i / w_i，按单位价值降序排序，依次装入，最后一件物品若无法完整装入则切取剩余容量比例；
  - **时空复杂度**：排序耗时 O(n log n)，装入过程耗时 O(n)，整体为 Θ(n log n)；**贪心算法必定可得全局最优解**。

### 矩阵连乘积的最优括号化
- **问题本质**：计算 n 个矩阵相乘 A_1 A_2 ... A_n，不同计算次序的标量乘法次数差异巨大；
- **状态转移方程**：设矩阵维度序列为 p_0, p_1, ..., p_n（其中矩阵 A_i 的维度为 p_(i-1) × p_i），m[i, j] 表示计算 A_i ... A_j 所需的最小标量乘法次数：
  - 当 i = j 时（单一矩阵）：m[i, j] = 0；
  - 当 i < j 时（枚举分割点 k，i ≤ k < j）：m[i, j] = min { m[i, k] + m[k+1, j] + p_(i-1) × p_k × p_j }（其中 i ≤ k < j）。
- **时空复杂度**：自底向上枚举链长、起点与分割点 k，**时间复杂度为 O(n^3)**，保存二维状态表**空间复杂度为 O(n^2)**。

### 最长公共子序列（LCS）
- **状态转移方程**：设序列为 X = (x_1, ..., x_m)，Y = (y_1, ..., y_n)，状态 c[i, j] 表示前缀 X_i 与 Y_j 的 LCS 长度：
  - 当 i = 0 或 j = 0 时：c[i, j] = 0；
  - 当 i > 0 且 j > 0，且 x_i = y_j 时：c[i, j] = c[i-1, j-1] + 1；
  - 当 i > 0 且 j > 0，且 x_i ≠ y_j 时：c[i, j] = max(c[i, j-1], c[i-1, j])。
- **时空复杂度**：暴力搜索子序列时间为指数级 O(n · 2^n)；动态规划填表**时间复杂度降为 O(mn)**，空间复杂度为 O(mn)。

## 4. 计算复杂性理论基础：P、NP、NPC 与 NP-Hard

1. **P 类问题（Polynomial）**：
   - 可以在**多项式时间（Deterministic Polynomial time）** 内由确定性图灵机求解的问题。如查找、排序、最小生成树、最短路径。
2. **NP 类问题（Non-deterministic Polynomial）**：
   - 可以在多项式时间内由不确定性图灵机求解，或者**可以在多项式时间内对给定的候选解进行有效验证**的问题。显然 P ⊆ NP。
3. **NP 完全问题（NP-Complete，NPC）**：
   - 如果一个问题 L 属于 NP 类，且 **NP 中的任何问题都可以在多项式时间内归约（Polynomial-time reduction）到 L**，则称 L 为 NP 完全问题；
   - NPC 问题是 NP 中最难的一批问题；只要其中任意一个 NPC 问题找到了多项式时间解法，则所有 NP 问题都可在多项式时间内求解（即证明 P = NP）；
   - **常见经典 NPC 问题**：0-1 背包问题（**判定版**）、旅行商问题 (TSP)（**判定版**）、哈密尔顿回路问题、三维匹配、顶点覆盖 (Vertex Cover)、团问题 (Clique)、布尔可满足性问题 (SAT)。
4. **NP 难问题（NP-Hard）**：
   - 所有 NP 问题都能在多项式时间内归约到它，但它本身**不一定属于 NP 类**（可能比 NP 问题还要困难，甚至无法在多项式时间内验证解）。例如，TSP 和 0-1 背包的**优化版**（求最值）属于 NP-Hard 而非 NPC。

## 5. 经典内部排序算法性能全景与稳定性判定

### 8 大经典内部排序算法性能全景大表

| 排序方法 | 最好时间复杂度 | 平均时间复杂度 | 最坏时间复杂度 | 辅助空间复杂度 | 稳定性 | 核心考点与典型特征 |
|---|---|---|---|---|:---:|---|
| **直接插入排序** | O(n) | O(n²) | O(n²) | O(1) | **稳定** | **序列基本有序时效率最高**；每趟将新元素插入已排序序列的合适位置 |
| **希尔排序（缩小增量）** | O(n) | O(n¹·³) ~ O(n²) | O(n²) | O(1) | **不稳定** | 分组插入排序，增量序列逐趟递减，最后一趟增量必须为 1 |
| **冒泡排序** | O(n) | O(n²) | O(n²) | O(1) | **稳定** | **每趟至少使一个最大/最小元素归位**；相邻元素逆序则两两交换 |
| **快速排序** | O(n log n) | O(n log n) | O(n²) | O(log n) ~ O(n) | **不稳定** | **综合平均性能最优的内部排序**；基本有序或完全逆序时退化为最坏 O(n²) |
| **简单选择排序** | O(n²) | O(n²) | O(n²) | O(1) | **不稳定** | **元素比较次数恒为 (n(n-1))/2，与初始排列状态完全无关** |
| **堆排序** | O(n log n) | O(n log n) | O(n log n) | O(1) | **不稳定** | **建堆时间为 O(n)**；适合从海量数据中筛选前 K 个最值（Top-K） |
| **二路归并排序** | O(n log n) | O(n log n) | O(n log n) | O(n) | **稳定** | 性能极其稳定不受初始排列影响，但需 O(n) 辅助存储空间 |
| **基数排序** | O(d(n + r)) | O(d(n + r)) | O(d(n + r)) | O(r) | **稳定** | 非基于比较的分配式排序，d 为关键字位数，r 为基数（如十进制 r=10） |

### 排序稳定性秒杀口诀
- **稳定排序算法**：直接插入排序、冒泡排序、二路归并排序、基数排序；
- **不稳定排序算法**：快速排序、希尔排序、简单选择排序、堆排序；
> **排序稳定性经典秒杀口诀**：
> “**快（快速）些（希尔）选（选择）一堆（堆排序）朋友聊天不稳定！**”
> 其余常见的插入、冒泡、归并、基数排序全部为稳定排序。

### 堆排序建堆与筛选调整算法模型
1. **大顶堆 vs 小顶堆定义**：
   - 完全二叉树中，若任意父结点的值均大于或等于其左右孩子结点的值（`K_i ≥ K_2i 且 K_i ≥ K_2i+1`），称为**大顶堆（大根堆）**；
   - 若任意父结点的值均小于或等于其左右孩子结点的值（`K_i ≤ K_2i 且 K_i ≤ K_2i+1`），称为**小顶堆（小根堆）**；
2. **初始建堆过程（自底向上）**：
   - 设数组有 n 个元素，从最后一个非叶子结点 `i = ⌊n / 2⌋` 开始，依次向前递减至根结点 1 进行筛选调整；
   - **初始建堆时间复杂度为 O(n)**（通过数学错位相减法求和证明，不是 O(n log n)！）；
3. **堆顶输出与调整过程（自顶向下）**：
   - 将堆顶元素输出（与当前堆底末尾元素交换，堆大小减 1）；
   - 将新的堆顶元素自顶向下与其较大的孩子结点比较下沉，单次调整时间复杂度为 **O(log n)**；
   - 重复执行 n - 1 次，整体堆排序时间复杂度为 **O(n log n)**。

## 6. 折半查找判定树模型与 ASL 计算

### 折半查找（二分查找）判定树模型
折半查找仅适用于**顺序存储的有序线性表**。
1. **中点划分规则**：设当前查找区间为 `[low, high]`，中间位置 `mid = ⌊(low + high) / 2⌋`（向下取整）；
2. **判定树形态**：
   - 判定树是一棵二叉搜索树，每个内部结点表示一次成功的关键字比较；
   - 判定树的叶子结点（外部结点 / 空指针方框）表示查找失败的区间；
3. **最大比较次数与树高定理**：
   - 具有 n 个结点的折半查找判定树的深度为 `h = ⌊log₂ n⌋ + 1`；
   - **查找成功时的最大比较次数不会超过判定树的深度**，即：
     `C_max = ⌊log₂ n⌋ + 1`

### 平均查找长度（ASL）求解两步法
1. **查找成功的 ASL（ASL_成功）**：
   `ASL_成功 = (1 / n) × ∑ᵢ₌₁ⁿ (各内部结点深度 × 1)`
   （即所有内部结点的层数之和除以结点总数 n）；
2. **查找失败的 ASL（ASL_失败）**：
   `ASL_失败 = (1 / (n + 1)) × ∑ⱼ₌₁ⁿ⁺¹ (各外部虚结点其父结点的深度)`
   （即所有外部空指针的父结点层数之和除以失败区间总数 n + 1）。

## 7. 第八章核心易错陷阱防坑指南与做题检查清单

### 核心易错陷阱防坑指南
1. **堆排序建堆时间复杂度误区**：
   - **陷阱**：考题问“初始序列自底向上建立大顶堆的时间复杂度”，错选成 O(n log n)；
   - **避坑法宝**：建立初始堆的时间复杂度严格为 **O(n)**！只有完整排序过程（建堆 + n-1 次调整）的总时间才是 **O(n log n)**。
2. **快速排序与二分查找的最坏退化**：
   - **陷阱**：以为快排总比归并快，忽略了有序序列会使其退化为 O(n²)；
   - **避坑法宝**：数据基本有序时，直接插入排序最快（O(n)），快速排序退化最严重（O(n²)）。
3. **简单选择排序比较次数独立性**：
   - **陷阱**：误以为如果序列已经排好序，简单选择排序比较次数会变少；
   - **避坑法宝**：简单选择排序每趟都要扫完剩余元素求最值，比较次数恒定为 `n(n-1) / 2`，与初始序列状态毫无关系！
4. **贪心算法不能解决 0-1 背包问题**：
   - **陷阱**：在 0-1 背包问题中按单位价值排序后贪心选取；
   - **避坑法宝**：0-1 背包具有重叠子问题和最优子结构，局部贪心无法保证全局最优，必须采用动态规划或回溯法；只有分数/部分背包才可用贪心算法。

### 第八章做题自检检查清单
- [ ] 先找题干是否有“独立子问题并合并”“最优子结构加重叠子问题”“局部最优不回退”“深度/广度优先解空间树”等唯一线索；
- [ ] 递推式先计算 `n^(log_b a)`，再比较非递归项；排序后再扫描时，用整体主导项而不是只看后半段；
- [ ] 背包先判断物品能否切分：可切分用分数背包贪心，不可切分优先 0-1 背包动态规划；
- [ ] 多空题分开作答：同一大题可同时问策略、时间、空间和具体数值，不能用一个结论覆盖全部空；
- [ ] 归并排序是典型的分治策略应用，不要因其局部子问题合并过程而误与动态规划混淆；
- [ ] 排序算法稳定性秒杀：“快些选一堆朋友聊天不稳定”！
