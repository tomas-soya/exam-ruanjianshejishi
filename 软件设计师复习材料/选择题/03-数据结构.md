# 第三章 数据结构

## 1. 先分清：逻辑结构、物理结构与运算

- **逻辑结构**只描述数据元素之间的关系，常见为线性、树形、图状和集合结构；不关心数据在内存中的位置。
- **存储结构（物理结构）**描述这种关系怎样落在存储空间中。考题若出现“相对位置连续/相邻”，优先想到顺序存储；若出现“指针（链）建立关系”，优先想到链式存储。
- **数据的运算**是插入、删除、查找、遍历等规则。相同逻辑结构采用不同存储结构，运算代价可能完全不同。

### 顺序存储

顺序存储把逻辑上相邻的元素放在**物理上相邻的存储单元**中，因此可由首地址和下标直接求地址：

`LOC(a[i]) = LOC(a[0]) + i × 单个元素长度`

- **核心优点**：**可随机访问表中的任一元素**（通过下标直接计算目标物理地址，时间复杂度为 O(1)）；存储密度高（无需额外指针开销）。
- **主要缺点**：
  - 在中间插入或删除通常需要搬移大量连续元素，时间复杂度为 O(n)，运算效率低；
  - 必须预先分配整块连续存储空间，容易产生外部碎片，容量扩展困难，无法有效利用分散的碎片化空间。
- **避坑提示**：不要把“顺序存储”误说成“按关键字有序存储”：前者讲物理连续位置，后者讲元素值的排序逻辑。

### 链式存储：与顺序存储的对照

- **核心优势**：元素可分散离散存放，无须连续空间；插入和删除只需要修改指针，不需移动元素；动态按需分配，便于利用碎片化内存。
- **主要局限**：
  - **不可随机访问表中的任一元素**，查找第 i 个元素必须沿链遍历，时间复杂度为 O(n)；
  - 需额外的指针域，存储密度低于顺序存储。
- **双向循环链表结点插入操作序列（高频考点）**：
  若需在 p 所指结点之后插入 s 所指结点，需执行 4 步指针赋值：
  1. `s->next = p->next;` （先使新结点 s 的后继指向 p 原来的后继结点）
  2. `s->prior = p;` （使新结点 s 的前驱指向 p）
  3. `p->next->prior = s;` （使原后继结点的前驱更新指向 s）
  4. `p->next = s;` （最后使 p 的后继更新指向 s）
  - **做题口诀**：“**先接新结点两端，再改后继前驱，最后断开改 p 后继**”。必须保证在执行 `p->next = s` 之前，原后继结点的地址已被使用和修改完毕，若过早修改 `p->next`，将导致原后继结点地址丢失！

## 2. 线性表、栈、队列：先锁定“受限访问端”

### 线性表

线性表中每个元素至多有一个直接前驱和一个直接后继；首元素无前驱，尾元素无后继。不要把“元素按值大小排列”当成线性表的定义。

### 栈

- 栈是**后进先出（LIFO）**的受限线性表，插入和删除都在栈顶进行。
- 常见应用：函数调用与返回、括号匹配、表达式求值、深度优先搜索的辅助存储。
- 栈空、栈满以及“栈顶指针指向栈顶元素还是下一个可用位置”必须结合题目约定判断；同一符号 `top` 在不同教材实现中可能不同。

### 队列与受限双端队列
- **队列基本性质**：**先进先出（FIFO）** 的受限线性表，队尾入队、队头出队；
- **循环队列核心公式（设数组容量为 m，空一个单元防混淆）**：
  - 队空条件：`front == rear`；
  - 队满条件：`(rear + 1) % m == front`；
  - 队列中有效元素个数：`(rear - front + m) % m`；
  - 入队操作：`rear = (rear + 1) % m`；出队操作：`front = (front + 1) % m`；
  - 若题目另设 `size/count` 变量或 `tag` 标志位，则无需空出单元，队列满容量即为 m。
- **双端队列（Deque）与受限输出/输入**：
  - **输出受限双端队列**：两端均可入队，但仅一端可出队；
  - **输入受限双端队列**：仅一端可入队，但两端均可出队；
  - **做题检验法**：通过状态机草稿逐步模拟出入队操作，重点关注已被排在出队端深处的元素是否被后续进入的元素“堵住”而无法先出。

## 3. 数组与特殊矩阵的压缩存储：通用地址计算模型

### 稀疏矩阵
- 非零元素远少于零元素时，采用**三元组顺序表（行号, 列号, 值）** 或 **十字链表（行指针与列指针）** 存储；
- 三元组表适合顺序查找与转置，十字链表适合频繁按行、按列插入和修改。

### 特殊对称矩阵与三角矩阵压缩存储（按行优先）
设矩阵 A_n × n，压缩存储到一维数组 M[k] 中：
1. **对称矩阵与下三角矩阵（只存下三角 i ≥ j）**：
   - 第 0 行存 1 个，第 1 行存 2 个，……，第 i-1 行存 i 个；
   - 前 i 行（从 0 到 i-1）共存有：1 + 2 + ... + i = (i(i+1)) / 2 个元素；
   - 第 i 行中，元素 A[i][j] 前面有 j 个元素；
   - **0 基下标映射公式**：k = (i(i+1)) / 2 + j（i ≥ j）；若 1 基下标则为 k = (i(i-1)) / 2 + j。
2. **上三角矩阵（只存上三角 i ≤ j）**：
   - 第 0 行存 n 个，第 1 行存 n-1 个……按行累加计算前序完整行元素数加上当前行偏移量；
   - 常数区：三角矩阵常在末尾保留一个单元保存对角线另一侧的常数 C。
3. **三对角矩阵（带状矩阵）**：
   - 只有主对角线及紧邻的上下两条次对角线有非零元素（|i - j| ≤ 1）；
   - 除第 1 行和第 n 行只有 2 个元素外，其余各行均有 3 个非零元素；
   - **矩阵下标与压缩数组下标双体系推导（设 n ≥ 2，i ≥ 2）**：设矩阵 A[1..n][1..n]（行标、列标均从 1 开始）。A[i][j] 前面有 i-1 行，其中第 1 行有 2 个元素，第 2 到 i-1 行每行有 3 个元素。故前 i-1 行元素总数为 2 + 3(i-2) = 3i - 4。在第 i 行中，首个非零元素列标为 i-1，故 A[i][j] 是本行第 j - (i-1) + 1 = j - i + 2 个元素。对于 i = 1 的首行直接验证即可。
   - **通用公式**：
     - 若**压缩数组下标从 1 开始**（即保存至 B[1..3n-2]），总位序 = 前 i-1 行总数 + 本行第几个元素 = (3i - 4) + (j - i + 2) = **2i + j - 2**。边界自检：首元素 A[1][1] → 2(1)+1-2=1；末行首元素 A[n][n-1] → 2n+(n-1)-2=3n-3；末元素 A[n][n] → 2n+n-2=3n-2。
     - 若**压缩数组下标从 0 开始**（即保存至 B[0..3n-3]），数组下标 = 总位序 - 1 = **2i + j - 3**。边界自检：首元素 A[1][1] → 2(1)+1-3=0；末行首元素 A[n][n-1] → 2n+(n-1)-3=3n-4；末元素 A[n][n] → 2n+n-3=3n-3。

### 二维数组行优先与列优先地址计算模型
设二维数组 A[0..m-1, 0..n-1]（或 A[1..m, 1..n]），每个元素占用 L 个存储单元，基地址为 Base：
1. **按行优先存储（Row-Major）**：
   - 元素按行连续存放。
   - 0 基下标：`Loc(A[i][j]) = Base + (i × n + j) × L`；
   - 1 基下标：`Loc(A[i][j]) = Base + [(i - 1) × n + (j - 1)] × L`；
2. **按列优先存储（Column-Major）**：
   - 元素按列连续存放。
   - 0 基下标：`Loc(A[i][j]) = Base + (j × m + i) × L`；
   - 1 基下标：`Loc(A[i][j]) = Base + [(j - 1) × m + (i - 1)] × L`；
3. **行优先与列优先偏移量相同的判定定理**：
   - 若二维方阵 A[1..N, 1..N]，按行偏移量为 `(i - 1) × N + (j - 1)`，按列偏移量为 `(j - 1) × N + (i - 1)`；
   - 两者相等即 `(i - 1) × N + (j - 1) = (j - 1) × N + (i - 1)`，化简得 `(N - 1)(i - j) = 0`；
   - 由于 N > 1，因此当且仅当 **i = j（即主对角线上的元素）** 时，行优先与列优先的存储偏移量恒相同。

## 4. 树与二叉树：性质公式与遍历判定定理

### 二叉树 5 大核心性质
1. **度与叶子节点关系**：在任意非空二叉树中，若叶子节点数为 n_0，度为 2 的节点数为 n_2，则恒有：
   n_0 = n_2 + 1
   （总节点数 n = n_0 + n_1 + n_2，总边数 B = n - 1 = 2n_2 + n_1）。
2. **层级节点上限**：第 i 层最多有 2^(i-1) 个节点（根在第 1 层）；
3. **深度节点上限**：深度为 k 的二叉树最多有 2^k - 1 个节点（满二叉树）；
4. **完全二叉树编号性质（从 1 起编号）**：
   - 节点 i 的双亲为 floor(i / 2)；左孩子为 2i（若 2i ≤ n），右孩子为 2i+1（若 2i+1 ≤ n）；
   - 若 n = 2m + 1，则编号为 n 的节点必定是编号为 m 的节点的**右孩子**；
   - 具有 n 个节点的完全二叉树深度为 ⌊log₂ n⌋ + 1 或 ⌈log₂(n+1)⌉（即 floor(log₂ n) + 1 或 ceil(log₂(n+1))）。

### 哈夫曼树（最优二叉树）核心原理与计算
- **定义**：带权路径长度（WPL）达到最小的二叉树，权值越大的叶子节点距离根越近；
- **构造特征**：每次选权值最小的两棵树合并，因此**哈夫曼树中不存在度为 1 的节点（n_1 = 0）**；
- **节点数量定理**：若有 n 个叶子节点（n_0 = n），则合并次数必为 n - 1（n_2 = n - 1），哈夫曼树的**总结点数必为奇数 2n - 1**；反之，若给定总结点数 N，叶子节点数必为 n_0 = (N + 1) / 2；
- **带权路径长度公式**：
  WPL = Σ(i=1..n) w_i × l_i = 各非叶子（分支）节点权值之和
- **前缀码性质**：哈夫曼编码中任何字符的编码都不能是另一字符编码的前缀，保证解码唯一性无二义性。

### 遍历序列与树结构判定定理
- **遍历顺序**：前序（根-左-右）、中序（左-根-右）、后序（左-右-根）、层序（按层从左至右）；
- **遍历相同定理**：
  - **中序序列 = 后序序列** ⇔ **所有非叶子节点均无右子树**（只有左子树）；
  - **前序序列 = 中序序列** ⇔ **所有非叶子节点均无左子树**（只有右子树）；
  - **前序序列 = 后序序列** ⇔ **只有根节点**（或各层仅有一个节点且形态退化）；
- **二叉树唯一确定原则**：已知两种遍历序列构造二叉树时，**必须包含中序遍历序列**；已知前序和后序通常无法唯一确定一棵二叉树。
- **层序遍历 + 中序遍历恢复二叉树解题模型**：
  1. **定根**：在当前子树节点集合中，**层序遍历中最先出现的元素必定是该子树的根节点**；
  2. **分左右**：在对应中序遍历序列中找到该根节点，根节点左侧的所有元素属于其**左子树**，右侧的所有元素属于其**右子树**；
  3. **递归推导**：分别在左、右子树节点子集中，再次找出层序遍历中最先出现的元素作为子树根，继续划分，直至确定每个结点的父子与左右孩子关系。
  - *典型推导示例*：层序遍历为 `ABCDEF`，中序遍历为 `BDAFEC`：
    - ① 全局根为 `A`；中序划分左子树 `{B, D}`，右子树 `{F, E, C}`；
    - ② 左子树 `{B, D}`：层序中 `B` 先出现，故 `B` 为根；中序中 `D` 在 `B` 右侧，故 `D` 为 `B` 的右孩子；
    - ③ 右子树 `{F, E, C}`：层序中 `C` 最先出现，故 `C` 为根；中序中 `F, E` 均在 `C` 左侧，故 `C` 无右孩子，左孩子集合为 `{F, E}`；
    - ④ 子集 `{F, E}`：层序中 `E` 先出现，故 `E` 为根；中序中 `F` 在 `E` 左侧，故 `F` 为 `E` 的左孩子；
    - ⑤ **结论**：`E` 为 `C` 的左孩子，`F` 为 `E` 的左孩子。
- **二叉排序树（BST）构造序列等价性判定**：
  - 构造二叉排序树时，按照序列先后顺序逐个插入结点（小于结点值往左插，大于结点值往右插）；
  - **关键结论**：不同插入顺序的序列可能构造出完全相同的 BST；但若左右子树的“根节点”插入次序改变（例如在根 95 下，序列 A 先插入 65 再插入 85，导致 65 为左子树根；而序列 B、C、D 均先插入 85，导致 85 为左子树根），则构造出的 BST 结构必然与其他序列不同！

## 5. 图：存储结构、遍历与核心图算法

### 图的表示与遍历
- **邻接矩阵**：空间复杂度 O(V^2)，判断任意两点间是否有边为 O(1)，适合**稠密图**；
  - **对称性判断**：若邻接矩阵对称，则为**无向图**；若不对称，则为**有向图**；
  - **环与拓扑排序**：若图中有向边构成环路（回路），则**不存在拓扑序列**（拓扑排序成立的前提是有向无环图 DAG）；
  - **强连通判定**：若有向图中任意两个顶点之间均存在双向路径互相可达，则该图为**强连通图**。
- **邻接表**：空间复杂度 O(V + E)，寻找顶点的邻接边速度快，适合**稀疏图**；
- **DFS（深度优先遍历）**：类似于树的先序遍历，借助**栈（或系统递归栈）** 实现；
- **BFS（广度优先遍历）**：类似于树的层序遍历，必须借助**队列**实现；
- **连通性概念**：无向图连通分支称为**连通分量**；有向图中任意两点均相互可达称为**强连通图**，其极大强连通子图称为**强连通分量**。

### 核心图算法横向对比

| 算法名称 | 解决问题 | 算法策略 | 时间复杂度 | 核心原理与适用场景 |
|---|---|---|---|---|
| **Prim 算法** | 最小生成树 (MST) | 贪心算法 | O(V^2) | **加点法**：从单个源点出发，每次将距离当前生成树最近的顶点加入树中。**适合稠密图** |
| **Kruskal 算法** | 最小生成树 (MST) | 贪心算法 | O(E log E) | **加边法**：按权值从小到大选边，利用并查集检测是否成环，避圈加入。**适合稀疏图** |
| **Dijkstra 算法** | 单源最短路径 | 贪心算法 | O(V^2) | 依次扩充最短路径顶点集合。**不能处理带负权边的图** |
| **Floyd 算法** | 所有顶点对间最短路径 | 动态规划 | O(V^3) | 三重循环更新路径矩阵。**可处理负权边，但不能有负权回路** |
| **拓扑排序** | 有向无环图 (DAG) 拓扑序列 | 入度消除 | O(V + E) | 循环选择入度为 0 的顶点输出并删除其所有出边；若输出顶点数 < \|V\| 则图中有环 |
| **关键路径法 (CPM)** | 工程最早/最迟完工时间 | 动态规划 | O(V + E) | **AOE 网中从源点到汇点具有最大长度的路径为关键路径**；关键活动时间余量 l - e = 0 |

## 6. 查找与内部排序：性能指标与算法全方位对比

### 查找算法与 ASL 通用计算
- **平均查找长度（ASL）**：为确定记录在查找表中位置所需进行的关键字比较次数的期望值，ASL = Σ(i=1..n) P_i × C_i（等概率下 P_i = 1 / n）；
- **折半查找（二分查找）通用模型**：
  - **前提条件**：仅适用于**顺序存储的有序表**，时间复杂度 O(log n)；
  - **判定树与 ASL 求解**：
    - 将折半查找过程绘制成二叉判定树（根节点为中间元素，左孩子为前半区间，右孩子为后半区间）；
    - **成功 ASL**：ASL_成功 = (1 / n) × Σ(各层) (各层节点数 × 层数)；
    - **失败 ASL**：以外部空节点（查找失败位置）计算，ASL_失败 = (1 / (n + 1)) × Σ(各外部节点) (外部节点数 × 对应父节点层数)；
- **散列表（Hash Table）**：
  - 装填因子 α = (表中记录数  n) / (散列表长度  m)；α 越大，散列冲突概率越高；
  - 冲突处理方法：开放定址法（线性探测、二次探测、伪随机探测）、链地址法（拉链法）、再散列法。

### 内部排序算法全景横向大对比

| 排序方法 | 平均时间复杂度 | 最好时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 | 核心考点与趟次特征 |
|---|---|---|---|---|---|---|
| **直接插入排序** | O(n^2) | O(n) | O(n^2) | O(1) | **稳定** | **序列基本有序时效率极高**；每趟将一个元素插入已排好的有序子表中 |
| **折半插入排序** | O(n^2) | O(n log n) | O(n^2) | O(1) | **稳定** | 仅减少关键字比较次数，元素移动次数不变 |
| **希尔排序** | O(n^(1.3)) | O(n) | O(n^2) | O(1) | **不稳定** | 缩小增量排序，最后一趟增量必须为 1 |
| **冒泡排序** | O(n^2) | O(n) | O(n^2) | O(1) | **稳定** | **每趟至少将一个最大/最小元素沉底到最终位置**；相邻逆序则交换 |
| **快速排序** | O(n log n) | O(n log n) | O(n^2) | O(log n) | **不稳定** | **基本有序时退化为最坏 O(n^2)**；基于分治基准划分，内部排序中综合平均速度最快 |
| **简单选择排序** | O(n^2) | O(n^2) | O(n^2) | O(1) | **不稳定** | **比较次数与初始排列无关**（恒为 (n(n-1)) / 2）；每趟选出最小元素与首位交换 |
| **堆排序** | O(n log n) | O(n log n) | O(n log n) | O(1) | **不稳定** | 大顶堆/小顶堆调整；适合海量数据中选前 K 个最大/最小元素（Top-K） |
| **二路归并排序** | O(n log n) | O(n log n) | O(n log n) | O(n) | **稳定** | 性能极其稳定不受初始分布影响，但需要 O(n) 辅助存储空间 |
| **基数排序** | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | **稳定** | 非基于比较的排序，d 为关键字位数，r 为基数（如十进制 r=10） |

#### 排序做题核心判断法则
1. **每趟必将至少一个元素确定在最终位置的排序**：冒泡排序（每趟最值沉底）、快速排序（每趟基准元素归位）、简单选择排序（每趟最值与端点交换）、堆排序（每趟堆顶元素与末尾交换）；
2. **第一趟排序结束后不保证将最小（或最大）元素放在其最终位置上的排序**：
   - **二路归并排序**（第一趟仅相邻两两归并形成局部有序小区间，不确定全局最值位置）；
   - 直接插入排序、折半插入排序、希尔排序。
3. **比较次数与初始排列状态无关的排序**：简单选择排序、二路归并排序、基数排序；
4. **数据基本有序时性能最好的排序**：直接插入排序（O(n) 线性时间）；
5. **数据基本有序时退化最严重的排序**：快速排序（退化为 O(n^2)）。

## 7. 线索二叉树与平衡二叉树（AVL）失衡旋转调整模型

### 线索二叉树（Threaded Binary Tree）原理与节点结构
在具有 n 个结点的常规二叉二叉链表中，每个结点有 2 个指针域（lchild 与 rchild），全树共有 2n 个指针域。其中有效孩子指针数为 n - 1 个，**空指针域恰好为 2n - (n - 1) = n + 1 个**。
- **线索化思想**：为了充分利用这 n + 1 个空指针域，并不增加额外存储空间：
  - 若结点的左孩子指针域为空，则将其改为指向该结点在某种遍历序列下的**前驱结点（左线索）**；
  - 若结点的右孩子指针域为空，则将其改为指向该结点在某种遍历序列下的**后继结点（右线索）**；
- **结点存储结构**：`[ lchild | ltag | data | rtag | rchild ]`
  - **ltag**：0 表示 lchild 指向左孩子；1 表示 lchild 为前驱线索；
  - **rtag**：0 表示 rchild 指向右孩子；1 表示 rchild 为后继线索；
- **核心做题优势**：在线索二叉树中查找某结点的前驱或后继结点，大多数情况下**无需借助系统栈或递归**即可在线性或常数时间内完成，极大加速了树的遍历。

### 平衡二叉树（AVL 树）定义与四种失衡旋转调整
- **平衡二叉树定义**：或者是一棵空树，或者是具有下列性质的二叉排序树：其左子树和右子树都是平衡二叉树，且**左子树和右子树的高度之差的绝对值不超过 1**；
- **结点的平衡因子（Balance Factor，BF）**：结点的左子树高度减去右子树高度（`BF = h_左 - h_右`），因此 AVL 树中任意结点的平衡因子只能是 **-1、0 或 1**；
- **失衡判定与最小不平衡子树**：新插入结点后，从插入位置**自底向上**寻找第一个平衡因子绝对值大于 1（即出现 2 或 -2）的祖先结点，以该结点为根的子树称为**最小不平衡子树**。只需调整这棵最小不平衡子树即可恢复全树平衡；
- **四种旋转调整策略对照表**：

| 失衡类型 | 导致失衡的插入位置 | 调整旋转动作 | 旋转核心口诀与变换结果 |
|---|---|---|---|
| **LL 型（左左）** | 在被破坏结点的**左孩子的左子树**上插入新结点 | **顺时针右单旋** | “左左右单旋”：左孩子上提为新根，原根节点下沉为新根的右孩子 |
| **RR 型（右右）** | 在被破坏结点的**右孩子的右子树**上插入新结点 | **逆时针左单旋** | “右右左单旋”：右孩子上提为新根，原根节点下沉为新根的左孩子 |
| **LR 型（左右）** | 在被破坏结点的**左孩子的右子树**上插入新结点 | **先左旋后右旋（双旋）** | “左右先左后右”：左孩子的右孙子上提，先绕左孩子逆时针左旋，再绕原根顺时针右旋 |
| **RL 型（右左）** | 在被破坏结点的**右孩子的左子树**上插入新结点 | **先右旋后左旋（双旋）** | “右左先右后左”：右孩子的左孙子上提，先绕右孩子顺时针右旋，再绕原根逆时针左旋 |

## 8. 拓扑排序算法流程与最小生成树唯一性判定

### 拓扑排序算法执行步骤与有向环检测
拓扑排序是针对**有向无环图（DAG）**的一种线性顶点排序，它使得对图中任意一条有向边 `<u, v>`，在序列中 `u` 均出现在 `v` 之前。
1. **统计入度**：扫描邻接表，计算图中所有顶点的初始入度（In-degree）；
2. **入度为零入队**：从图中选取所有**入度为 0 的顶点**压入队列或栈中；
3. **循环消除出边**：
   - 从队列中弹出一个顶点输出到拓扑序列中；
   - 遍历该顶点的所有出边，将对应后继顶点的入度减 1；
   - 若某后继顶点的入度减为 0，则将该后继顶点立即压入队列；
4. **判环定理**：
   - 若最终输出到拓扑序列中的顶点总数 **等于** 图中的总顶点数 |V|，则该图是一个有向无环图（拓扑排序成功）；
   - 若输出顶点总数 **小于** |V|，则证明**图中必定存在有向环路（回路）**，剩余未输出的顶点均处于死锁环路中，入度无法清零。
5. **拓扑序列的不唯一性**：当某一时刻入度为 0 的顶点有多个时，选择哪一个先出队是任意的，因此同一个有向无环图**通常存在多条合法拓扑序列**。

### 最小生成树（MST）唯一性判定定理
对于带权连通无向图 G：
1. **权值互不相同时**：若图中**所有边的权值均两两不相等**，则图 G 的**最小生成树是唯一的**；
2. **存在相同权值时**：若图中存在权值相同的边，则图 G 的最小生成树形态（顶点的连接拓扑）**可能不唯一**；
3. **总权值恒定唯一性**：无论最小生成树形态是否唯一，**所有最小生成树的所有边的权值总和恒定唯一且相等**！

## 9. 第三章核心易错陷阱防坑指南与做题检查清单

### 核心易错陷阱防坑指南
1. **完全二叉树编号下标基数（0 基 vs 1 基）混淆**：
   - **陷阱**：直接套用双亲结点编号为 `i / 2`，忽视了题目是从下标 0 开始存放；
   - **避坑法宝**：从 1 起编号时，结点 i 的左孩子为 `2i`，右孩子为 `2i + 1`，双亲为 `floor(i / 2)`；从 0 起编号时，结点 i 的左孩子为 `2i + 1`，右孩子为 `2i + 2`，双亲为 `floor((i - 1) / 2)`。
2. **哈夫曼树中度为 1 的结点数误区**：
   - **陷阱**：在计算哈夫曼树结点数时，错误假设存在单分支；
   - **避坑法宝**：哈夫曼树每次选出两棵子树合并为一棵新子树，因此**哈夫曼树中绝对没有度为 1 的结点（n₁ = 0）**！若有 n 个叶子，总结点数严格等于 `2n - 1`。
3. **二叉树前序与后序无法唯一确定一棵树**：
   - **陷阱**：题干给出前序和后序遍历，试图推导唯一的树结构；
   - **避坑法宝**：前序和后序只能确定祖先与子孙关系，不能确定左还是右。**唯一确定二叉树必须包含中序遍历**！
4. **快速排序最坏退化条件**：
   - **陷阱**：误以为初始序列基本有序时快排依然最快；
   - **避坑法宝**：基本有序或逆序是快速排序的最坏输入场景，退化为冒泡排序的 `O(n²)` 时间复杂度。
5. **AVL 树旋转中心选取错误**：
   - **陷阱**：失衡后随意挑选结点旋转；
   - **避坑法宝**：必须找到**最小不平衡子树的根节点**（从插入点往上第一个平衡因子绝对值超过 1 的结点），根据插入位置相对于它的方向（LL, RR, LR, RL）严格旋转。
