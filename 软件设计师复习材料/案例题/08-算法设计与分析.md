## 1. 算法题型识别与考场通用破题流程

### 1.1 试题识别与题面结构
- **试题位置**：下午试题四（必答题，满分 15 分）。
- **题面三件套**：
  1. **问题背景与数学建模说明**：明确输入规模、约束条件及优化目标（求最大收益、最小成本、最优路径等）；
  2. **核心算法策略描述**：阐述算法设计思路（是分阶段自底向上填表、深度优先搜索、还是自顶向下分治递归）；
  3. **C 语言完整函数代码**：包含数据结构定义、主循环、动态规划递推或回溯递归核心逻辑，挖空 4 至 5 处（填空 8～10 分）；
  4. **小问设问**：通常包括“采用何种算法策略”、“写出状态转移方程”、“C 代码填空”、“手算小算例结果”与“分析时间/空间复杂度”。

### 1.2 考场四步快速解题流水线
```text
第 1 步：读代码骨架，锁定算法策略 → 查表嵌套循环→DP；递归回退→回溯；独立子树→分治
  ↓
第 2 步：审数组维度，明确递推状态 → 弄清 dp[i][j] 代表什么，写出选与不选的 max/min 方程
  ↓
第 3 步：紧扣上下文，填写 C 代码空 → 看循环边界（< 还是 <=）、看指针解引用（*）、看递归基与回退
  ↓
第 4 步：代入小算例，推算结果与复杂度 → 草稿纸手工模拟填表；数循环层数/树高写出标准大 O
```

### 作答卡 ALG-01：识别算法设计策略

- **【题型识别】**：常见设问：“根据以上说明和 C 代码，该算法采用了 (n) 算法设计策略。”（通常 2～4 分）。
- **【目标产出】**：算法策略标准中文名称（动态规划法、分治法、回溯法、贪心法、分支限界法）。
- **【题干取证】**：
  - 观察 C 代码的主体控制结构；
  - 观察问题是否具有“最优子结构”与“重叠子问题”。
- **【推理步骤（特征速查三步法）】**：
  1. **看数据结构与控制流**：
     - 若代码维护了**一维/二维数组（如 `c[i][j]`, `dp[i]`）**，通过双重/三重嵌套 `for` 循环自底向上填表，利用已计算的子状态推导当前状态 → **动态规划法（Dynamic Programming）**；
     - 若代码采用**递归函数**，通过 `for` 循环依次尝试解空间分支，进入前有 `if (剪枝条件)`，递归调用返回后有**完全对称的撤销恢复语句**（如 `cw = cw - w[i];`） → **回溯法（Backtracking）**；
     - 若代码将规模为 n 的问题均等划分为互不相交的子问题（如二分、三分），分别递归求解并合并结果 → **分治法（Divide and Conquer）**；
     - 若代码每一步只做局部最优选择（如按单位价值排序后单向装入），绝不回溯 → **贪心法（Greedy）**；
     - 若代码使用队列（BFS）或优先队列，按广度优先遍历解空间树并利用限界函数剪枝 → **分支限界法（Branch & Bound）**。
- **【答案形态】**：必须写规范全称：`动态规划法` 或 `回溯法`（不写单字“递归”）。
- **【知识依赖】**：[五大核心算法策略对比表](#51-五大核心算法设计策略核心判定与对比)。
- **【易错与自检】**：
  - *陷阱*：将“递归”误填为策略（递归只是一种程序实现机制，其背后的策略可能是分治、回溯或 DP 备忘录）；
  - *自检*：有查表自底向上就是动态规划，有试探回退剪枝就是回溯法。

### 作答卡 ALG-02：状态定义与递推方程

- **【题型识别】**：常见设问：“写出求解该问题的递推状态转移方程及边界条件。”（通常 3～6 分）。
- **【目标产出】**：状态物理含义说明 + 分段数学递推公式 + 初值边界。
- **【题干取证】**：题干中对目标函数的定义（最大化价值、最小化标量乘法次数、最少编辑操作）。
- **【推理步骤】**：
  1. **定义状态变量物理意义**：
     - 背包：`dp[i][j]` 表示前 i 个物品、总重不超过 j 时的最大总价值；
     - 矩阵链乘：`m[i][j]` 表示计算矩阵子链 Aᵢ…Aⱼ 所需的最小标量乘法次数；
     - LCS 子串：`c[i][j]` 表示以 X[i] 和 Y[j] 结尾的最长公共子串长度；
  2. **分析当前阶段的决策选择**：
     - **选或不选（0-1 背包）**：
       `dp[i][j] = max(dp[i-1][j], dp[i-1][j - w[i]] + v[i])`；
     - **最优分割点枚举（区间 DP）**：
       `m[i][j] = min { m[i][k] + m[k+1][j] + p[i-1] × p[k] × p[j] }`（`i ≤ k < j`）；
     - **连续匹配中断直接归零（LCS 连续子串）**：
       若字符相等为 `c[i-1][j-1] + 1`，字符不等直接置 `0`；
  3. **明确边界初值**：`dp[0][j] = 0`，`dp[i][0] = 0`，`m[i][i] = 0`。
- **【答案形态】**：清晰分段公式，指明各变量取值范围。
- **【知识依赖】**：[动态规划最小覆盖集六大经典模型](#52-动态规划dp题型突破与最小覆盖集)。
- **【易错与自检】**：
  - *陷阱*：下标偏移写错（如容量写成 `j - w[i]`，漏掉减号；或未减 1 导致数组越界）；
  - *自检*：检查容量不足装下物品 i（`j < w[i]`）时的分支是否直接继承 `dp[i-1][j]`？

### 作答卡 ALG-03：C 语言核心代码填空

- **【题型识别】**：常见设问：“根据以上说明和 C 代码，填充 C 代码中的空 (1)～(n)。”（通常 8～10 分，每空 2 分）。
- **【目标产出】**：精确的 C 语言表达式或语句片段。
- **【题干取证】**：仔细阅读挖空周围的上下文、循环头、变量类型声明及函数形参。
- **【推理步骤（代码填空五步口诀）】**：
  1. **第 1 步：看循环找边界（数组起始是 0 还是 1）**：
     - 检查外层循环变量初始值（`i = 0` 还是 `i = 1`）；
     - 循环条件是严格小于（`i < n`）还是小于等于（`i <= n`）；
  2. **第 2 步：看形参找指针（是否需要解引用）**：
     - 若形参是 `int *bestW`，在函数内部赋值必须写 `*bestW = cw;`；
     - 涉及数值交换时，调用端传地址 `swap(&a[i], &a[j])`，接收端加 `*`；
  3. **第 3 步：看递归找出口（Base Case）**：
     - 回溯到达叶子结点的判断：`if (i > n) { ... return; }` 或 `if (k == n)`；
     - 分治终止条件：`if (low >= high) return a[low];`；
  4. **第 4 步：看状态找转移（直接翻译递推方程）**：
     - 如果是求最大值：`if (temp > max_val) { max_val = temp; }`；
     - 初始化赋初值：求最小值置极大值（`INT_MAX`），求最大值置 `0`；
  5. **第 5 步：看回溯找撤销（完全对称扣减）**：
     - 在进入递归 `backtrack(i + 1)` 之前有累加 `cw += w[i]`，递归返回后必定填完全对称的扣减：`cw -= w[i];`。
- **【答案形态】**：精准 C 语法代码（如 `dp[i-1][j]`、`cw + w[i] < bestW`、`*bestX = x`）。
- **【知识依赖】**：[C 代码填空实战避坑清单](#57-案例试题四-c-代码填空实战避坑清单)。
- **【易错与自检】**：
  - *陷阱*：漏写语句末尾分号；数组指针漏写 `*`；混淆赋值 `=` 与等于比较 `==`；
  - *自检*：填入的代码语法是否完全自洽？会不会发生死循环或数组越界？

### 作答卡 ALG-04：动态规划状态转移方程与表格填充代码填空动作卡

- **【题型识别】**：常见设问：“写出该问题的递推状态转移方程及边界条件” / “填充动态规划填表 C 语言核心代码中的空 (1)～(n)” / “计算最优计算顺序与最少运算次数”。（通常 6～10 分）。
- **【目标产出】**：分段状态转移方程、填表双重/三重循环边界、C 语言数组下标位移表达式及推演算例数值。
- **【5 大高频真题动态规划模型状态转移方程与代码填空对照大表】**：

| 经典 DP 问题模型 | 状态定义与物理含义 | 标准递推状态转移方程（纯文本与 Unicode） | C 语言代码核心填空模式 |
|---|---|---|---|
| **0-1 背包问题** | `dp[i][j]`：前 i 个物品、背包限重 j 时的最大总价值 | `dp[i][j] = dp[i-1][j]` (当 `j < w[i]`);<br>`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])` (当 `j >= w[i]`) | `dp[i-1][j-w[i]] + v[i]` 或外层物品、内层容量循环 |
| **矩阵链乘问题** | `m[i][j]`：计算矩阵子链 Aᵢ…Aⱼ 所需的最小标量乘法次数 | `m[i][j] = 0` (当 `i = j`);<br>`m[i][j] = min { m[i][k] + m[k+1][j] + p[i-1]×p[k]×p[j] }` (`i <= k < j`) | `m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]`，分割点 k 枚举 |
| **最长公共子串 (LCS)**| `c[i][j]`：以 X[i] 和 Y[j] 结尾的严格连续公共子串长度 | `c[i][j] = c[i-1][j-1] + 1` (若 `X[i] == Y[j]`);<br>`c[i][j] = 0` (若 `X[i] != Y[j]`) | `c[i-1][j-1] + 1`，不等时清零；记录 `max_len` |
| **编辑距离 (Edit Dist)**| `d[i][j]`：字符串 A[1..i] 转换为 B[1..j] 所需的最少编辑次数 | 若 `A[i] == B[j]`，则 `d[i][j] = d[i-1][j-1]`;<br>否则 `d[i][j] = min(d[i-1][j], d[i][j-1], d[i-1][j-1]) + 1` | `min(d[i-1][j], min(d[i][j-1], d[i-1][j-1])) + 1` |
| **钢条切割问题** | `r[n]`：长度为 n 的钢条能够卖出的最大收益 | `r[n] = max { p[i] + r[n-i] }` (`1 <= i <= n`)，边界 `r[0] = 0` | `q = max(q, p[i] + r[j-i])`，一维填表 |

- **【手动推演算例流水线（以矩阵链乘为例）】**：
  1. **画对角线三角形表格**：按链长 `r = 2, 3, ..., n` 逐层自左下向右上填充；
  2. **记录最优分割点 `s[i][j]`**：若 `s[1][4] = 1` 且 `s[2][4] = 3`，对应加括号方案为 `(A1((A2A3)A4))`；
  3. **代入算例核算总次数**：严格按照 `p[i-1] × p[k] × p[j]` 逐阶段累加，避免心算失误。

### 作答卡 ALG-05：回溯法递归求解框架（解向量/剪枝/恢复现场）模板卡

- **【题型识别】**：常见设问：“写出回溯算法递归终止条件” / “写出第 k 层的约束与限界剪枝条件” / “填充现场恢复语句”。（通常 4～8 分）。
- **【目标产出】**：解空间遍历框架、剪枝 `if` 条件式、镜像对称现场恢复赋值语句。
- **【通用回溯法递归 C 语言代码骨架】**：
  ```c
  void backtrack(int t) {
      if (t > n) { // 到达叶子节点（递归基准出口）
          if (cw < bestW) { // 刷新全局最优解
              bestW = cw;
              for (int i = 1; i <= n; i++) bestX[i] = x[i]; // 保存最优解向量
          }
          return;
      }
      for (int i = 0; i <= 1; i++) { // 枚举当前分支（如选0或选1）
          x[t] = i;
          if (constraint(t) && bound(t)) { // 剪枝判断：约束函数与限界函数
              cw += w[t] * x[t];           // 进入子树前：修改现场
              backtrack(t + 1);            // 递归深入下一层
              cw -= w[t] * x[t];           // 递归返回后：镜像对称恢复现场！
          }
      }
  }
  ```
- **【双重剪枝与现场恢复三大铁律】**：
  1. **可行性约束剪枝 (Constraint)**：当前局部累加代价若已超出硬性上限（如累加重量 `cw + w[t] > W`），直接剪枝；
  2. **最优性限界剪枝 (Bound)**：当前累加价值加上剩余所有物品的最大可能价值之后，仍不优于已知全局最优解 `bestV`，直接剪枝；
  3. **现场恢复绝对镜像对称**：
     - 若进入前为 `cw += w[t]; cp += p[t]; visited[t] = 1;`；
     - 递归返回后**必须逐行完全反向扣减**：`cw -= w[t]; cp -= p[t]; visited[t] = 0;`。
- **【知识依赖】**：[回溯法最小覆盖集模型](#53-回溯法backtracking题型突破与最小覆盖集)。

### 作答卡 ALG-07：算法时空复杂度分析与渐进记号速查卡

- **【题型识别】**：设问：“根据以上说明和 C 代码，该算法的时间复杂度为 (n)，空间复杂度为 (m)（用大 O 符号表示）。”（通常 2～4 分）。
- **【目标产出】**：标准大 O 符号渐进表达式（如 `O(n log n)`, `O(n²)`, `O(n × W)`）。
- **【推理步骤】**：
  1. **看循环嵌套重数**：
     - 单层循环扫描：`O(n)`；
     - 两层嵌套循环：`O(n²)` 或 `O(m × n)`（如 0-1 背包外层物品 n，内层容量 W，为 `O(n × W)`）；
     - 三层嵌套循环（如矩阵链乘）：外层链长，中层起点，内层分割点，为 `O(n³)`；
  2. **看二叉/三叉递归与树高**：
     - 假币称重（三分分治）：树高 `log₃ n`，每层代价 `O(1)` → 时间复杂度为 `O(log₃ n)` 或 `O(log n)`；
     - 堆排序全过程：建堆为 `O(n)`，排序下滤为 `O(n log n)`，总时间复杂度为 `O(n log n)`；
  3. **空间复杂度检查**：
     - 若只使用常数个临时变量，辅助空间复杂度为 `O(1)`；
     - 若开辟了与输入规模相同的二维表 `dp[m][n]`，辅助空间复杂度为 `O(m × n)`。
- **【答案形态】**：大 O 规范写法（如 `O(n log n)`, `O(n³)`）。
- **【知识依赖】**：[算法题常见时间复杂度阶数速查表](#56-算法题常见时间复杂度阶数速查)。

### 作答卡 ALG-08：分治称重与 KMP next 数组推导卡

- **【题型识别】**：设问：“计算最坏情况下需要称重的次数” / “给出模式串对应的 next 数组值”。
- **【目标产出】**：整数称重次数，或一维整数数组。
- **【推理步骤】**：
  1. **假币三分称重**：
     - 每次将硬币均分为 3 堆，比较其中两堆，确定假币所在的三分之一；
     - 最坏称重次数公式：**`⌈log₃ n⌉`**（如 8 枚硬币：`⌈log₃ 8⌉ = 2` 次；27 枚硬币为 3 次）；
  2. **KMP next 数组手算推导（传统 1-indexed 规范）**：
     - 规定：`next[1] = 0`, `next[2] = 1`；
     - 对于第 j 位，截取子串 `P[1 .. j-1]`，找出其**既是真前缀又是真后缀的最长公共子串长度 L**；
     - 则 `next[j] = L + 1`；若无公共前后缀，`next[j] = 1`。
- **【答案形态】**：整数值或数值序列（如 `next: 0 1 1 2 3`）。
- **【知识依赖】**：[分治称重与 KMP 算法详解](#54-分治法divide-and-conquer与模式匹配)。

## 3. 典型真题全链路演练与真题锚点

以已验收真题 2022 年上半年试题四（矩阵链乘动态规划算法）（请在历年真题页面查看） 为例，演示从题面到标准答案的全流程：

### 3.1 题面关键信息提炼
- **问题背景与递归式**：
  - 矩阵链乘问题：给定 n 个矩阵序列 A₁ × A₂ × ... × Aₙ，维数序列为 `seq` 数组，求使得总乘法运算次数最少的完全加括号方案；
  - 动态规划递归式：
    ```text
    cost[i][j] = 0                                                                           (若 i = j)
    cost[i][j] = min_{i ≤ k < j} (cost[i][k] + cost[k+1][j] + seq[i] × seq[k+1] × seq[j+1]) (若 i < j)
    ```
- **算法代码结构**：
  - 函数 `matrixChain(int n, int seq[], int cost[][MAX], int trace[][MAX])` 采用三重循环自底向上填表：
    - 外层循环链长跨度增量 `p`（从 1 到 n-1）；
    - 中层循环起始下标 `i`（从 0 到 n-p-1），计算终止下标 `j = i + p`；
    - 内层循环断开分割点 `k`（从 i 到 j-1），寻找最小乘法代价并记录最优断点 `tempTrace`。

### 3.2 逐小问推导演练
- **问题 1（C 语言核心代码填空 (1)～(4)）**：
  - **取证与推理**：
    - 空 (1)：矩阵链从第 i 个开始，跨度为 p，终止下标为 `j = i + p`（或 `i + p`）；
    - 空 (2)：内层最优断开位置枚举，根据递归式 `i ≤ k < j`，内层初值为 `k = i`，故初始候选最优分割点填 `k`；
    - 空 (3)：标量乘法代价累计，根据状态转移方程，从矩阵 i 到 j 在点 k 处断开的代价为左段最优代价、右段最优代价与当前标量乘法代价之和，填 `cost[i][k] + cost[k + 1][j] + seq[i] * seq[k + 1] * seq[j + 1]`；
    - 空 (4)：记录最优分割点到追踪表，内层循环结束后将记录的最优分割点 `tempTrace` 存入追踪表数组，填 `trace[i][j] = tempTrace`。
  - **答案**：
    - `(1) j = i + p（或 i + p）`
    - `(2) k`
    - `(3) cost[i][k] + cost[k + 1][j] + seq[i] * seq[k + 1] * seq[j + 1]`
    - `(4) trace[i][j] = tempTrace`（套用 [作答卡 ALG-03](#作答卡-alg-03c-语言核心代码填空)）。
- **问题 2（算法策略与时空复杂度判定 (5)～(6)）**：
  - **取证与推理**：
    - 该算法将问题分解为相互重叠的子问题并自底向上查表填表，属于**动态规划算法（Dynamic Programming）**；
    - 代码由外层链长增量、中层起点下标、内层最优分割点枚举三层嵌套循环组成，时间复杂度为 **`O(n³)`**（或 `O(n^3)`）。
  - **答案**：
    - `(5) 动态规划算法（Dynamic Programming）`
    - `(6) O(n³)`（套用 [作答卡 ALG-01](#作答卡-alg-01识别算法设计策略)、[作答卡 ALG-05](#作答卡-alg-05计算时空复杂度)）。
- **问题 3（算例手工推演与加括号顺序 (7)～(8)）**：
  - **取证与推理**：
    - 给定实例 n = 4，矩阵维数分别为 A₁(15×5)、A₂(5×10)、A₃(10×20)、A₄(20×25)，维数序列为 `15, 5, 10, 20, 25`；
    - 经填表推演得出最优加括号顺序为：`A1 * ((A2 * A3) * A4)`（或 `A1((A2A3)A4)`）；
    - 所需的最少乘法运算次数为 `5375`。
  - **答案**：
    - `(7) A1 * ((A2 * A3) * A4)`（或 `A1((A2A3)A4)`）
    - `(8) 5375`（套用 [作答卡 ALG-04](#作答卡-alg-04手动推演算例与状态值)）。

## 5. 支撑知识详解（下钻算法卡库）

### 5.1 五大核心算法设计策略核心判定与对比
| 算法策略 | 核心机制与特征 | 最优子结构 | 重叠子问题 | 典型试题场景 |
|---|---|:---:|:---:|---|
| **动态规划法 (DP)** | 自底向上查表或备忘录记忆，分解为重叠子问题 | 具备 | 具备 | 0-1背包、矩阵链乘、LCS、编辑距离、钢条切割 |
| **回溯法 (Backtracking)** | 深度优先搜索（DFS）解空间树，遇到死路则撤销回退 | 不一定 | 通常不强调 | n皇后、哈密尔顿回路、最小重量机器设计 |
| **分治法 (Divide & Conquer)** | 将问题均等划分为互不相交的子问题，递归求解后合并 | 具备 | 不具备（相互独立） | 假币称重、归并排序、快速排序 |
| **贪心法 (Greedy)** | 每一步做出局部最优选择，绝不回溯 | 具备 | 不强调 | 活动选择、霍夫曼编码、Dijkstra 最短路 |
| **分支限界法 (Branch & Bound)** | 广度优先（BFS）遍历解空间树，利用上/下界函数剪枝 | 具备 | 可重叠 | 0-1背包分支限界搜索 |

### 5.2 动态规划（DP）题型突破与最小覆盖集

#### (1) 0-1 背包问题（0-1 Knapsack）
- **状态转移方程**：
  - `j < w[i]` 时：`dp[i][j] = dp[i - 1][j]`
  - `j ≥ w[i]` 时：`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i])`
- **复杂度**：时间复杂度 `O(n × W)`，空间复杂度 `O(n × W)`（滚动数组可优化为 `O(W)`）。

#### (2) 矩阵链乘问题（Matrix Chain Multiplication）
- **状态转移方程**：
  - `i = j` 时：`m[i][j] = 0`
  - `i < j` 时：`m[i][j] = min { m[i][k] + m[k + 1][j] + p[i - 1] × p[k] × p[j] }`（`i ≤ k < j`）
- **复杂度**：时间复杂度 `O(n³)`，空间复杂度 `O(n²)`。

#### (3) 最长公共子串（LCS Substring，严格连续）
- **状态转移方程**：
  - 若 `X[i - 1] == Y[j - 1]`：`c[i][j] = c[i - 1][j - 1] + 1`
  - 若 `X[i - 1] ≠ Y[j - 1]`：`c[i][j] = 0`（连续中断，直接归零！）
- **复杂度**：时间复杂度 `O(m × n)`。

#### (4) 字符串编辑距离（Edit Distance）
- **状态转移方程**：
  `dp[i][j] = min(dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + cost)`（字符相同 cost=0，不同 cost=1）。
- **复杂度**：时间复杂度 `O(m × n)`。

#### (5) 钢条切割问题（Cutting Rod）
- **递推方程**：`r[n] = max { p[i] + r[n - i] }`（`1 ≤ i ≤ n`）。时间复杂度为 `O(n²)`。

#### (6) 凸多边形最优三角剖分（Optimal Polygon Triangulation）
- **同构性**：与矩阵链乘完全同构，时间复杂度 `O(n³)`。

### 5.3 回溯法（Backtracking）题型突破与最小覆盖集

#### (1) n 皇后问题（n-Queens Problem）
- **剪枝条件**：
  - 同列冲突：`x[i] == x[k]`；
  - 同对角线冲突：`abs(x[i] - x[k]) == abs(i - k)`。

#### (2) 最小重量机器设计（双约束剪枝与回溯现场恢复）
- **双重剪枝**：价格上限 `cp + c[i][j] <= cc` 且重量最优限界 `cw + w[i][j] < bestW`；
- **对称现场恢复**：递归调用后必须完全镜像执行 `cw -= w[i][j]; cp -= c[i][j];`。

#### (3) 哈密尔顿回路（Hamiltonian Circuit）
- 检查顶点相邻（`graph[x[k-1]][x[k]] == 1`）且未被访问；放置第 n 个顶点还需检查回程边（`graph[x[n-1]][x[0]] == 1`）。

#### (4) 0-1 背包问题（回溯限界法与贪心松弛上界剪枝）
- **问题描述**：n 个物品，重量 `w[i]`，价值 `v[i]`，背包容量 W。选入物品使总价值最大且总重量不超过 W。
- **解空间树**：二叉树。第 k 层向左分支表示装入第 k 个物品（`x[k] = 1`），向右分支表示不装入第 k 个物品（`x[k] = 0`）。
- **上界函数 BOUND 设计（贪心松弛）**：
  将物品按单位价值 `v[i] / w[i]` 从大到小预排序。当前已考察到第 k 个物品，累计重量为 cw，累计价值为 cp：
  - 尽量装入后续物品；当某物品无法完整装入时，允许装入其一部分（背包问题贪心松弛），计算出剩余物品的最大理论价值上界；
  - 若该理论上界 `BOUND ≤ fp`（`fp` 为当前已找到的最优解价值），则该子树不可能突破现有最优解，直接剪枝。
- **非递归 BKNAP 回溯骨架（解题核心）**：
  - 向左深入装入：`cw = cw + w[k]; cp = cp + v[k]; Y[k] = 1; k = k + 1;`
  - 叶子结点更新最优解：若 `fp < cp`，则 `fp = cp; fw = cw; X = Y;`
  - 向上剪枝回退：若 `BOUND ≤ fp`，持续回溯 `while (k != 0 && Y[k] != 1) { k = k - 1; }`；
  - 撤销选择并转向右分支：`Y[k] = 0; cw = cw - w[k]; cp = cp - v[k]; k = k + 1;`

### 5.4 分治法（Divide and Conquer）与模式匹配
- **假币检测（天平称重）**：三分递归，时间复杂度为 `O(log₃ n)`，最少称重次数为 `⌈log₃ n⌉`；
- **KMP 模式匹配与 next 数组**：利用真前后缀公共长度避免主串回溯，匹配时间为 `O(m + n)`。

### 5.5 堆排序（Heap Sort）与希尔排序（Shell Sort）
- **大顶堆性质**：`A[i] ≥ A[2i + 1]` 且 `A[i] ≥ A[2i + 2]`；
- **建堆复杂度**：严格数学证明为 **`O(n)`**（从最后一个非叶子节点 `⌊n/2⌋ - 1` 逆序下滤）；
- **排序全过程复杂度**：最好、最坏与平均时间复杂度均为 **`O(n log₂ n)`**，空间复杂度为 `O(1)`，不稳定排序；
- **希尔排序（Shell Sort）**：缩小增量排序，空间复杂度 `O(1)`，不稳定排序。

### 5.7 案例试题四 C 代码填空实战避坑清单
1. **0-indexed vs 1-indexed**：严格核实数组是从 0 开始还是从 1 开始，循环条件是 `< n` 还是 `≤ n`；
2. **指针解引用**：形参为指针时，赋值必须加 `*`（如 `*bestW = cw`）；数值交换必须传地址 `&x, &y`；
3. **递归基与退出条件**：进入递归前必须检查递归终止条件，防止无限递归栈溢出；
4. **查表初值与偏移**：求最小值初始置 `INT_MAX`，求最大值置 `0`；查表偏移量注意减 1；
5. **回溯状态完全对称撤销**：进入递归前如何累加，递归返回后必须完全镜像扣减。
