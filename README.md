# 软件设计师刷题与智能复习工作台

免费开源的软考软件设计师备考工具。把历年真题、章节训练、错题复习、学习资料和 AI 答疑放在同一页面，答题进度保存在自己的电脑上。

作者：[tomas-soya](https://github.com/tomas-soya)。仓库地址：[exam-ruanjianshejishi](https://github.com/tomas-soya/exam-ruanjianshejishi)。对题目、刷题功能有任何建议，欢迎[提交 issue](https://github.com/tomas-soya/exam-ruanjianshejishi/issues)。

## 有哪些特色

- **历年真题与章节特训**：包含 1560 条客观题记录、162 组案例题，以及 52 份物理卷索引；页面将重复卷归并为 45 份可选试卷。按年份、科目筛选，也可以围绕薄弱章节训练。记录数量包含重复题及组卷，不等于独立知识点数。
- **三种答题模式**：考试模式交卷后查看答案；练习模式边做边看解析；记忆模式用于温习。支持自动暂存与继续答题。
- **智能复习**：错题本和复习队列根据失分、最近练习时间和复习周期安排优先级，可将掌握的题目移出重点复习。
- **复习资料**：13 个选择题章节和 8 个案例专题提供基础复习内容。交卷后自动更新动态资料默认关闭；推荐用本地 Agent 按需读取学习记录，生成个人 Markdown 复习资料。
- **AI 助教**：围绕当前题目、试卷或考点提问，结合本地资料讲解。考试模式保留答案隔离，使用辅助功能需按页面提示切换模式。
- **案例题判分**：按照评分要点比对作答，提供失分反馈，并支持人工复核与调整。AI 未配置、不可用或返回无效结果时，保留答卷并标记待评分，不进行规则评分。恢复连接后，可在报告中重新进行 LLM 评分；旧规则降级结果也可补评，人工覆核成绩保留。
- **数据自己掌控**：学习记录存放于本地 SQLite，支持备份、恢复；基础刷题无需配置 AI。

## 快速上手与使用方式

### 方式一：下载已发布免安装版本（推荐考生使用，开箱即用）

无需安装 Node.js、无需配置任何代码环境，直接下载解压即用：

1. 前往 **[Releases 页面](https://github.com/tomas-soya/exam-ruanjianshejishi/releases)** 下载最新版本：
   - **单文件免安装版 (`RuankaoExam-SingleExe-xxxx.exe`)**：**最推荐**。单文件双击直接运行，自动启动服务并调起浏览器打开。
   - **绿色便携压缩包 (`RuankaoExam-Portable-xxxx.zip`)**：解压到本地任意目录后，双击目录内的 `软件设计师刷题平台.exe`（或 `启动控制台调试模式.bat`）即可启动。
2. 启动后浏览器将自动打开 [http://127.0.0.1:3124](http://127.0.0.1:3124)。题库与复习材料已完整内嵌，做题进度与错题记录自动保存在本机的 `data/app.db`。

> **提示**：首次运行时若弹出 Windows Defender 智能扫描提示，点击“更多信息”并选择“仍要运行”即可。

### 方式二：源码运行（跨平台 / 开发者使用）

适合 macOS、Linux 用户或有二次开发需求的用户：

1. 需要 **Node.js 22.17 或更新版本**（需支持内置 `node:sqlite`）。首次使用建议选择 Node.js 22 的维护版本。
2. 下载仓库 ZIP 或使用 Git 克隆：
   ```sh
   git clone https://github.com/tomas-soya/exam-ruanjianshejishi.git
   ```
3. 进入项目根目录并运行：
   ```sh
   npm start
   ```
4. 浏览器访问 [http://127.0.0.1:3124](http://127.0.0.1:3124)。项目内置前端离线静态资产，无需安装第三方依赖或执行前端编译构建；退出时按 `Ctrl+C`。需要安装工作区链接用于二次开发时可运行 `npm install`。

## 开始学习

1. 在“历年真题”选择一份试卷，或在“章节特训”选择考点。
2. 选择考试、练习或记忆模式，开始作答；案例题在对应输入区填写答案。
3. 交卷后查看成绩、参考解析和考点资料。来源答案存在争议时，以解析说明为准。
4. 在“错题本”和“复习队列”回顾失分，在“复习资料”阅读基础章节与个人资料。
5. 离开页面后可从答题历史或继续答题入口恢复进度。

## 配置 AI

打开右上角“设置”，填写 OpenAI 兼容接口地址、自己的 API Key 和模型名称；可查询模型、测试连接，再保存配置。模型服务由你自己选择，本项目不附带密钥。AI 服务提供商可能按用量收费，这与项目免费无关。

AI 请求会把相关题目、资料上下文和你的作答或提问发给你配置的服务商。只在接受该服务商的数据政策后启用。API Key 和配置存储在本地数据库中；**密钥并非加密保存**，请保护电脑及备份文件。

## 生成个人复习资料（推荐本地 Agent）

推荐在完成一组练习后，让本地 Agent 工具只读 SQLite 学习记录，结合本地题库与基础章节，按需生成 Markdown。这样可以自行选择复盘范围、检查推导和练习步骤，再保存资料。

先从“设置 → 学习记录备份与跨设备迁移”确认当前运行版本的数据库路径。便携版与源码版可能使用不同文件，不要凭目录名判断哪份记录最新。使用 SQLite 的只读连接（例如 Node.js `new DatabaseSync(dbPath, { readOnly: true })`），多表查询放在同一读事务中；不要调用应用初始化、迁移或资料重生成入口。只读取所需会话、作答和评分字段，不读取 `app_settings`、密钥、配置或浏览器数据，不上传完整数据库。

可向本地 Agent 提供以下任务：

> 只读我指定的本地学习数据库，分析最近已提交练习中的真实错题与已确认案例失分。仅查询 exam_sessions、exam_answers、case_reviews、wrong_questions、review_queue 中必要的学习字段；不读取配置、凭据或未提交答卷。待评分、未作答和未选做题单独标明，不当成已确认失分；已得满分的小问不扩写为薄弱点。结合本地题库中的题面、参考解析、代码与基础资料核对，以概念、判定条件/公式、解题步骤、陷阱、检查清单、独立变式和分离答案组织复习资料。输出到独立的个人 Markdown 文件，公式使用纯文本/Unicode；个人统计和来源对账另留本地证据。不修改数据库、评分、学习进度、正式题库或现有基础章节，不自动联网或发送资料。

也可直接使用“复习资料 → 个人 Markdown”：

1. 选择最近 1–100 次已提交练习和题型，下载复习任务 ZIP。包内有 `TASK.md`、错题证据、相关基础章节与本地图示；不需要提供数据库或 API 配置。按范围内每题最近一次实质作答整理，排除背题练习；待评分、待复核、未作答和未选做题单独标明，不作为已确认失分。缺失的章节或图片会在 `evidence.json` 中提示。
2. 解压后，让本地 Agent 只读任务包，按 `TASK.md` 生成自包含的个人 Markdown。此步骤由用户在自己的 Agent 工具中执行。
3. 回到“个人 Markdown”，选择文件并预览，核对后点击“保存个人资料”。单文件上限 2 MB，使用 UTF-8 编码，公式仅用纯文本或 Unicode。
4. 更新已有资料时先选中该资料，再导入新版本；保存前可对照当前版本。版本下拉框支持查看历史与对比，恢复历史会建立新版本，保留全部旧版；各版本均可下载。

生成后核对关键结论和代码，使用闭卷变式检查是否会做。模型生成和原有自动评分仍可能有误，结构检查不能代替内容核验。个人资料保存在本机学习数据库中，随学习记录备份，不放进公开题库或发布包；与原有“错题复习要点”独立管理。复习任务包含个人作答，请自行保存在本地。

应用内“每次提交刷题后更新动态复习资料”默认关闭，旧版本升级后没有显式设置也视为关闭；已有资料与待处理任务保留，启动时不自动续跑。需要自动更新时，在“设置 → 大模型 API 配置”勾选该项并保存；交卷、案例补评分和人工复核才会触发后台资料更新。资料页的手动更新/重试入口仍可按需使用。关闭开关会停止后续自动触发，已经启动的后台处理批次可完成。

## 备份与恢复

在“设置 → 学习记录备份与跨设备迁移”导出数据库。在另一份相同版本应用中导入以恢复记录。导入会替换当前学习数据库，先备份当前记录。

数据库位置为 `apps/exam-service/data/app.db`。完整数据库备份可能包含 API 配置与密钥，请勿公开上传或附到 issue。手动复制数据库时先停止服务，以免漏掉尚未写回的 WAL 数据。

题目使用与整理来源无关的中性 ID。旧版本记录在首次启动或导入时自动升级题号引用，升级前会在数据目录的 `backups/` 创建备份；作答内容、分数和 API 配置保持不变。出现题号冲突时升级会回滚，请保留备份并反馈问题。

## 手机和平板使用

默认只允许本机访问。在可信的家庭局域网中，可显式监听局域网地址：

```powershell
# Windows PowerShell
$env:HOST = '0.0.0.0'
npm start
```

```sh
# macOS / Linux
HOST=0.0.0.0 npm start
```

手机连接同一 Wi-Fi，打开控制台显示的局域网地址。此模式共享同一份学习记录，应用没有多用户登录与访问鉴权；请勿直接部署到公网。

发现题目、答案或图片问题时，请提供页面显示的题号、卷名、问题描述与预期结果；功能建议请描述使用场景。不要提交个人数据库、API Key、Token 或包含密钥的截图。

项目链接统一维护在 `apps/exam-web/public/project-info.js`。公开反馈请使用[仓库 issue](https://github.com/tomas-soya/exam-ruanjianshejishi/issues)。

开发验证：

```sh
npm test
npm run verify
```

`npm test` 使用独立临时数据库验证题库、评分、答案隔离与应用服务，不访问真实 AI 服务或已有学习数据库。`npm run verify` 核对发布资源及敏感文件边界。

修改公开资源后，运行 `node scripts/update-release-manifest.cjs` 更新校验清单，再执行验证。

Windows 用户也可构建便携包：运行 `node scripts/build-portable.mjs`，随后运行 `node scripts/portable/verify-portable.mjs` 检查完整性。构建需有 .NET C# 编译器才能生成启动程序，输出位于 `dist/portable/`，不进入 Git。已有输出目录会被保护；再次构建请设置新的 `PORTABLE_DATE` 标识，例如 `20261012-release2`。仓库提供 Node.js 22.17.1 的运行时许可证，使用其他版本构建前需准备对应版本的官方许可证文件。
