# 软件设计师刷题与智能复习工作台

免费开源的软考软件设计师备考工具。把历年真题、章节训练、错题复习、学习资料和 AI 答疑放在同一页面，答题进度保存在自己的电脑上。

作者：[tomas-soya](https://github.com/tomas-soya)。仓库地址：[exam-ruanjianshejishi](https://github.com/tomas-soya/exam-ruanjianshejishi)。对题目、刷题功能有任何建议，欢迎[提交 issue](https://github.com/tomas-soya/exam-ruanjianshejishi/issues)。

## 有哪些特色

- **历年真题与章节特训**：包含 1560 条客观题记录、162 组案例题，以及 52 份物理卷索引；页面将重复卷归并为 45 份可选试卷。按年份、科目筛选，也可以围绕薄弱章节训练。记录数量包含重复题及组卷，不等于独立知识点数。
- **三种答题模式**：考试模式交卷后查看答案；练习模式边做边看解析；记忆模式用于温习。支持自动暂存与继续答题。
- **智能复习**：错题本和复习队列根据失分、最近练习时间和复习周期安排优先级，可将掌握的题目移出重点复习。
- **动态资料**：13 个选择题章节和 8 个案例专题提供基础复习内容；结合真实错题与案例失分，生成和更新个人薄弱考点资料，并从资料进入相关训练。
- **AI 助教**：围绕当前题目、试卷或考点提问，结合本地资料讲解。考试模式保留答案隔离，使用辅助功能需按页面提示切换模式。
- **案例题判分**：按照评分要点比对作答，提供失分反馈，并支持人工复核与调整。未配置或无法连接 AI 时，部分功能采用规则评分，不能替代正式考试评分。
- **数据自己掌控**：学习记录存放于本地 SQLite，支持备份、恢复；基础刷题无需配置 AI。

## 启动

需要 **Node.js 22.17 或更新版本**（需支持 `node:sqlite`）。Windows、macOS 和 Linux 均可使用源码运行；首次使用建议选择 Node.js 22 的当前维护版本。

下载仓库 ZIP 并解压，或使用 `git clone https://github.com/tomas-soya/exam-ruanjianshejishi.git` 克隆。进入项目根目录后运行：

```sh
npm start
```

打开 [http://127.0.0.1:3124](http://127.0.0.1:3124)。项目内置前端运行资源，启动无需安装第三方依赖或编译前端。控制台出现 SQLite 实验性提示属于 Node.js 的提示信息。保持控制台运行；退出时按 `Ctrl+C`。

需要安装工作区链接用于开发时可运行 `npm install`，日常使用不需要这一步。

## 开始学习

1. 在“历年真题”选择一份试卷，或在“章节特训”选择考点。
2. 选择考试、练习或记忆模式，开始作答；案例题在对应输入区填写答案。
3. 交卷后查看成绩、参考解析和考点资料。来源答案存在争议时，以解析说明为准。
4. 在“错题本”和“复习队列”回顾失分，在“复习资料”阅读基础章节与个人资料。
5. 离开页面后可从答题历史或继续答题入口恢复进度。

## 配置 AI

打开右上角“设置”，填写 OpenAI 兼容接口地址、自己的 API Key 和模型名称；可查询模型、测试连接，再保存配置。模型服务由你自己选择，本项目不附带密钥。AI 服务提供商可能按用量收费，这与项目免费无关。

AI 请求会把相关题目、资料上下文和你的作答或提问发给你配置的服务商。只在接受该服务商的数据政策后启用。API Key 和配置存储在本地数据库中；**密钥并非加密保存**，请保护电脑及备份文件。

## 备份与恢复

在“设置 → 学习记录备份与跨设备迁移”导出数据库。在另一份相同版本应用中导入以恢复记录。导入会替换当前学习数据库，先备份当前记录。

数据库位置为 `apps/exam-service/data/app.db`。完整数据库备份可能包含 API 配置与密钥，请勿公开上传或附到 issue。手动复制数据库时先停止服务，以免漏掉尚未写回的 WAL 数据。

题目使用与整理来源无关的中性 ID。旧版本记录在首次启动或导入时自动升级题号引用，升级前会在数据目录的 `backups/` 创建备份；作答内容、分数和 API 配置保持不变。出现题号冲突时升级会回滚，请保留备份并反馈问题。

## 手机和平板使用

默认只允许本机访问。在可信的家庭局域网中，可显式监听局域网地址：

```powershell
# Windows PowerShell
$env:HOST = '0.0.0.0'
npm start
```

```sh
# macOS / Linux
HOST=0.0.0.0 npm start
```

手机连接同一 Wi-Fi，打开控制台显示的局域网地址。此模式共享同一份学习记录，应用没有多用户登录与访问鉴权；请勿直接部署到公网。

## 反馈与参与

发现题目、答案或图片问题时，请提供页面显示的题号、卷名、问题描述与预期结果；功能建议请描述使用场景。不要提交个人数据库、API Key、Token 或包含密钥的截图。

项目链接统一维护在 `apps/exam-web/public/project-info.js`。公开反馈请使用[仓库 issue](https://github.com/tomas-soya/exam-ruanjianshejishi/issues)。

开发验证：

```sh
npm test
npm run verify
```

`npm test` 使用独立临时数据库验证题库、评分、答案隔离与应用服务，不访问真实 AI 服务或已有学习数据库。`npm run verify` 核对发布资源及敏感文件边界。

修改公开资源后，运行 `node scripts/update-release-manifest.cjs` 更新校验清单，再执行验证。

Windows 用户也可构建便携包：运行 `node scripts/build-portable.mjs`，随后运行 `node scripts/portable/verify-portable.mjs` 检查完整性。构建需有 .NET C# 编译器才能生成启动程序，输出位于 `dist/portable/`，不进入 Git。已有输出目录会被保护；再次构建请设置新的 `PORTABLE_DATE` 标识，例如 `20261012-release2`。仓库提供 Node.js 22.17.1 的运行时许可证，使用其他版本构建前需准备对应版本的官方许可证文件。
